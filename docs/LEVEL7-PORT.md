# Level7 修复移植：纳入 GPT小龙娘 v0.3.0

当前产品版本：`0.3.0`。此前集成候选号为 `0.4.0+codex.20261005.gpt-level7`；按 GPT 产品独立版本整理，没有撤销该候选中的修复。基于 GPT 双语候选，参考小鲸鱼 For-Codex v0.4 已完成的修复逐项移植。参考版本的运行代码与已发布提交 `c86b055e8f24473ca76324d6e67145d65c596c41` 一致。

本次不覆盖小龙娘的形象、双语词典、无旧梗设计和气泡可读布局，也不把上游的硬件验证直接算作小龙娘已通过。

## 对照与处理

| Level7 问题 | 小龙娘处理 |
| --- | --- |
| 并行账户扣费误归到失败对话 | 单轮费用与账户区间差额分离；缺少可靠模型价格时保留 token 与状态，不编造单轮金额。旧账本通过读取视图澄清归属。 |
| 并行场景缺少直观费用反馈 | 独立“账户新增消耗”通知，按账户/币种/计量上下文累计并去重，显示后确认；确认丢失仅重试确认，不重复显示金额。首次样本建立新基准，不补弹历史扣费。 |
| 极小金额舍入遗漏 | 差额与累计使用十进制精度表示，展示时才保留两位小数；小额正值有简短说明。 |
| 历史账户无入口（#163） | 新增匿名历史账户与币种选择，账户总额与单轮估算分别展示，支持中英切换。 |
| 额度类型/窗口覆盖（#181） | 筛选账户额度来源，按窗口时长分别更新，同文件/跨文件合并，并处理过期与登录边界。 |
| 初始化与保存竞争（#97） | 设置按字段合并、串行提交；读取期间的用户修改不会被迟到结果覆盖。 |
| 配置读取错误冒充空配置（#88） | 区分缺失、损坏和不可读；错误可见，拒绝用默认值覆盖原数据。 |
| 编辑器缓存与保存冲突 | 打开前读取最新配置，提交携带版本，冲突保留草稿并要求重新加载。 |
| 已有屏幕名称丢失（#108） | 保留普通屏、选择屏及候选项的名称元数据，同时保留本地化键。 |
| 输入法确认候选误触快捷键 | 组字期间 Enter/Esc 不保存或关闭编辑器。 |
| 气泡失败后队列卡住（#172/#195） | 场景与队列项所有权一致；渲染失败、取消和替换释放相应占用，旧回调不能清掉新内容。关闭消耗提示也会丢弃已排队通知。 |
| 隐藏/图片回退后不按时关闭（#188） | 保存绝对截止时间，恢复时检查剩余时间；常驻提示不被改成限时提示。 |
| 取消拖拽保存错误位置（#79） | 取消、丢失捕获及失焦与正常松手分开，恢复已提交位置，不接受取消事件的零坐标。 |
| 连击期间短暂失去命中 | 角色、输入路由和窗口形状共用稳定轮廓，覆盖按压与回弹，过滤过期按键样本；保留真正透明区穿透。 |
| 整组音效不完整/订阅模式不一致 | 顺序播放完整片段，统一事件设置与主音量；成功音效开关独立于消耗显示。未恢复繁忙专属音效。 |
| 音频裁剪上下文泄漏（#135） | 解码和预览分离，关闭、异常及迟到回调释放资源。不能据此声称解决所有 Mac 睡眠问题。 |
| 峰谷规则越过有效期 | 到有效期边界停止推算并提示更新，不改变实际计费。 |
| 通用文字溢出（#159） | 保留小龙娘已有双语安全区域、字号下限、长文详情及统一预览；新增通知使用同一排版，而非覆盖成小鲸鱼旧布局。 |

## 验证边界

测试使用隔离数据及独立无头 Edge，不读取或操作日常安装插件。账户通知覆盖并行、重复结束、丢确认后重载、关闭期间累计、语言切换、最小尺寸与历史账本。连击检查覆盖实际浏览器鼠标事件与 Alpha/稳定轮廓；它不等同于 Windows 原生跨窗口穿透验收。

macOS PR #128 的平台实现与来源保留。本次没有 Mac 实机、蓝牙/特定声卡首音、系统睡眠或 Windows 原生窗口验收。#177 全局空白点击关闭仍不采用；#186 跳转聊天、#190 自定义 POST 等新功能不属于本次修复范围。

## 使用与回退

正式安装包、源码及校验材料见 GPT小龙娘独立仓库的 [v0.3.0 Release](https://github.com/Yang-huai406/GPT-Dragon-Girl/releases/tag/v0.3.0)。构建和移植验证在工作区完成，没有操作日常安装的插件。接收者主动运行安装器时，脚本会为那次安装生成独立备份和回执。回滚恢复旧代码，保留新增账本和媒体。

语言在设置中的“语言 / Language”切换。费用气泡中的“账户新增”包含并行任务、其他设备及延迟入账的可能性，不是逐请求账单；单轮费用没有可靠归属时继续显示用量与状态。
