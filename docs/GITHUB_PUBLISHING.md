# GitHub 发布：GPT小龙娘 v0.3.0

GPT小龙娘是支持中英双语、去除旧角色内置玩梗内容的余额插件产品线，使用自己的仓库和发布版本。

- 发布标题：GPT小龙娘 v0.3.0。
- 仓库：[Yang-huai406/GPT-Dragon-Girl](https://github.com/Yang-huai406/GPT-Dragon-Girl)，属于 Yang-huai406，由其维护；默认分支为 `main`。
- 标签：`v0.3.0`；正式附件位于 [v0.3.0 Release](https://github.com/Yang-huai406/GPT-Dragon-Girl/releases/tag/v0.3.0)。
- GPT v0.3.0 与前身小鲸鱼 For-Codex v0.4 是不同产品版本沿革；本项目发布不改变上游仓库的标签、Release 或 Latest。
- 提交保留上游 MeteorNOX 的版权和仓库归属、Yang-huai406 的 Codex 适配贡献、1llysviel 的 macOS PR #128 署名与平台实现，以及素材来源。公开源码不携带私人 Git 历史。
- 对外附件：安装包、源码包、GitHub材料包、SHA-256及验证摘要。私有收据、个人配置和测试profile不得进入提交或附件。
- 当前内部ID仍为 `api-balance-whale`：接收者安装时与同ID小鲸鱼共用插件槽及数据，并不是可同时安装的第二实例。README已说明此限制。

发布校验包括：版本与标签一致、公开内容和隐私检查通过、附件哈希一致，以及 Release 正文明示验证范围。上传后重新下载附件并复核哈希，不能只依据上传命令成功。浏览器与单元测试不替代原生 Windows 或 Mac 实机验收。

发布正文、检查清单与提交说明在 GitHub 材料包中；产品安装、验证与回滚步骤见 [中文 README](../README.md) 和 [English README](../README.en.md)。仓库内历史文档只记录对应开发时期，其中的候选包、未上传或旧版本信息不描述本次正式版本的发布状态。
