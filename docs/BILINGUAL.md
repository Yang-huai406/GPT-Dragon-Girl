# 中英本地化与气泡排版候选版

版本：`0.3.0+codex.20261004.bilingual`。本次只在工作区开发、验证和打包，没有安装到开发者的日常插件环境。

## 内容与语言

默认点击内容为余额、已观测用量和 GPT 摸头 GIF。旧角色梗、旧随机预设及其回退路径已停用。历史原装模板以内容指纹兼容处理，不覆盖用户新增的自定义句子。高需求失败不再有独立气泡、专属音效或开关例外；费用与 token 记录保留。

设置中选择“语言 / Language”下的中文或 English，即时更新并记住选择。静态界面、动态编辑器、气泡、默认提醒、托盘和运行状态文案使用共享词典。控件分组使用语义标记，不根据中文文字判断。自定义文字、媒体名称和外部服务返回的专有内容不自动翻译。

语言切换不改变币种、真实金额、汇率、计价配置、结算日、时区或用户草稿；数字和日期只调整显示格式。后端显示字段具有稳定文案键，旧存储仍保持原数据格式。

## 排版

正式气泡与编辑器预览使用同一安全内容区及测量逻辑。字体和图片解码完成后验证每一行文字的实际边界；字号至少 12px。小角色不会把气泡文字缩成不可读的小字，气泡会在可用视口内保持适当宽度。

超长自定义内容显示摘要和“查看详情 / View details”，原文完整保留。金额不使用省略号；极小可用空间不能容纳所有内容时，完整内容通过详情查看。金额、语言、字体或窗口尺寸变化只重新排版，不重播 GIF、不重新抽取随机内容、不重置提示计时。

主题保留白紫配色。表单允许必要换行，窄面板使用纵向滚动，控件和草稿原位保留。

## 验证与限制

单元测试使用隔离数据，界面测试使用独立的无头 Edge 配置目录与本地模拟数据；没有使用或控制已安装插件。覆盖中英切换、字段占位符、旧模板兼容、表单草稿/焦点/选区、繁忙提示开关和气泡尺寸组合。

保留已有 macOS PR #128 平台代码。本次没有 macOS 实机验收，也没有把无头浏览器测试称为原生 Electron 窗口验收。

## 回退

工作区中旧分享包与源码保留在独立目录；放弃本候选即可回到旧基线。将来如明确安装到某台电脑，安装器会为该次安装生成独立备份和回执，使用随包的回滚入口恢复旧代码，保留最新账本与用户素材。语言偏好与模板元数据是兼容字段；读时迁移不覆写原配置。
