# GPT小龙娘开发过程与产品范围

这是公开的产品沿革摘要，不包含原始聊天、个人配置或运行账单。当前产品为 **GPT小龙娘 v0.3.0**，支持中英双语并去除旧角色内置玩梗内容，已集成前身小鲸鱼的后续修复。它使用独立产品版本线，在 [Yang-huai406/GPT-Dragon-Girl](https://github.com/Yang-huai406/GPT-Dragon-Girl) 发布。

## 开发过程

1. **DSH 挂件到 Codex 桌面适配**：保留角色、拖动、点击、气泡和声音，采用独立 Electron 透明窗口、原生窗口跟随及受限本地通信。不修改 Codex 安装文件，不向聊天正文注入界面。余额查询从固定厂商扩展为当前 API 配置与兼容接口。
2. **小鲸鱼计量与隐私基础**：区分余额、已观测费用、订阅额度和 token；支持 USD/CNY 显示换算、账户隔离、跨午夜基线、长期汇总及待结算恢复。失败并不代表此前调用免费，缺少记录也不能当作零费用。公开包隔离个人配置、账本与日志。
3. **双模式和设置框架**：形成 API/订阅切换、概览/用量/设置分页、独立桌面/跟随模式、角色与气泡编辑、音效组与手感、本地 JSON 素材工坊。保留 macOS PR #128 的平台实现和署名。
4. **窗口可靠性与位置记忆**：分别处理窗口可见性、透明合成、绘制区域和层级；泡泡完成淡出后才回收区域，菜单间隙只保留悬停、不拦截正常透明点击。位置意图独立于临时动画及视口大小，避免启动、缩窗和无关设置覆盖记忆。
5. **GPT小龙娘外观**：使用用户提供的立绘和摸头 GIF，统一图标、主体、恢复图及白紫主题；沿用单图与 CSS 互动，不虚构多状态图集。停用要米图片，保留文字提醒和自定义素材。
6. **无旧梗、双语与安全排版**：移除旧角色随机台词及繁忙专属提示，默认只展示余额/用量和摸头动画；增加中英文即时切换。正式气泡和编辑预览共用安全区域，长文保留详情，切换语言保留草稿、焦点、选区和计时。
7. **Level7 修复移植**：前身 For-Codex v0.4 的账户通知去重、费用归属、高精度、匿名历史账本、额度窗口合并、设置冲突、输入法、队列恢复、取消拖动、音频清理与稳定连击轮廓逐项整合。保留 GPT 版本独有的双语和排版，不整包覆盖回旧角色。
8. **GPT v0.3.0 正式发布**：按 GPT 产品独立版本统一清单、运行版本、安装包与中英文文档，使用独立仓库及标签 [`v0.3.0`](https://github.com/Yang-huai406/GPT-Dragon-Girl/releases/tag/v0.3.0)；并不代表撤销前身 v0.4 的修复。构建、打包和验证在工作区内完成，没有将发布包安装到制作者日常环境。

## 产品功能

- 透明角色窗口跟随 Codex，可切换独立桌面；拖动、位置记忆、大小、吸附、显示恢复与显式退出。
- API 余额、账户新增消费、今日已观测费用及历史匿名账户账本；账户增量去重，不冒充某轮的精确账单。
- 本轮 token 与配置单价估算；没有可靠归属时保留未知及状态，不把并行任务消费算给失败任务。
- 可用的订阅五小时/每周额度快照，来源与窗口分别合并；本机 token 与官方额度分开显示。
- 中英文界面、可配置气泡模块、图片、提醒、角色、音效、按压手感，以及本地素材导入导出。
- 高精度内部计算与两位显示、参考汇率、按当前服务识别的峰谷信息；语言切换不改币种或计费语义。

## 明确的取舍和未实现能力

全局空白点击关闭没有启用：宿主编辑点击不代表已读挂件提示，额外全局监听也会增加误关闭及跨平台维护成本。保留明确关闭入口和原本超时，见 [#177 取舍](OUTSIDE-CLICK-DECISION.md)。

本地工坊不是在线市场；独立桌面不是壁纸层；退出挂件不会停止 Codex 调用。当前没有通用厂商订阅套餐模板、自动输入框避让、点击通知跳转聊天、自定义余额 POST/body、退款净额账本或完整任务阶段换角色功能。
