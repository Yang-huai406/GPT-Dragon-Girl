# GPT小龙娘 v0.3.0 验证范围

本文件描述 GPT小龙娘 [v0.3.0 正式版](https://github.com/Yang-huai406/GPT-Dragon-Girl/releases/tag/v0.3.0) 的验证范围，不以旧版本测试数字代替成品核验。测试使用隔离资料，无本机已安装插件操作。

## 已有当前功能证据

- Level7 移植后365项单元测试通过，覆盖费用归属、账户通知、额度解析、高精度、配置错误与冲突、队列、取消拖拽、音频及双语行为。
- 7项账户/历史账本浏览器流程通过，包括并行去重、确认丢失后重载、关闭期间累计、双语及最小尺寸。
- 58项双语气泡布局检查、4项语言与通知集成检查通过。
- GPT图像在独立无头Edge中完成120次角色点击和18次透明像素对照；稳定命中覆盖按压/回弹。该测试关闭模拟气泡以隔离角色手势，**不等同于Windows原生跨窗口穿透测试**。

## 本次成品门禁

本次统一为 GPT 产品线的 `0.3.0` 版本，并从最终源码包重新验证。Release 附件中的 `verification-report.json` 记录实际运行结果；`SHA256SUMS.txt` 与单独的 `.sha256` 可核对下载。检查包括版本一致、压缩包 CRC、内容哈希、依赖、隐私允许清单及源码重建一致。

公开包排除个人配置、密钥、账本、日志、浏览器profile、真实截图和私有安装回执；PNG/GIF/MP3及内嵌恢复图的附加元数据检查独立于画面质量。

## 尚未宣称通过

本次没有GPT原生Windows窗口穿透、Mac实机与睡眠、特定声卡/蓝牙首音、真实订阅账号、多设备或长期稳定性验收。浏览器和单元验证不能代替这些场景。

账户新增费用可能包含并行、其他设备或延迟入账；单轮估算不等于提供商最终账单。订阅快照不等于实时配额，本机token不覆盖其他设备。

## 用户测试

检查中英文切换及草稿保持、拖动后重启位置、气泡长文/金额、并行费用一次提示、开关关闭后累计、历史账户、声音组和取消拖拽。先在愿意测试的电脑完整解压安装，按该次安装生成的回执回滚；不要删除账本作为回滚手段。
